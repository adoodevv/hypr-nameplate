
  @NAME@ desktop: keyboard cheat sheet            (q closes this window)
  SUPER is the Windows key.

  APPS
    SUPER + Return          Terminal
    SUPER + Space           Main menu: everything in one place (or click the logo in the bar).
                            Type to search, Enter to pick, Escape or Backspace goes back.
                            Appearance (theme, font, gaps, dock, animations, lock blur),
                            Install / Remove (apt, snaps, Flathub), Update (with a
                            Timeshift snapshot first, if you have Timeshift)
    SUPER + ALT + SPACE     App grid (start typing to search, arrows to move, Enter)
    SUPER + SHIFT + Return  Web browser (SUPER + SHIFT + B works too)
    SUPER + SHIFT + ALT + B Web browser, private window
    SUPER + SHIFT + F       Files
    SUPER + K               This cheat sheet
    SUPER + Escape          Power options (lock, log out, restart, shut down)
    SUPER + CTRL + L        Lock the screen
    SUPER + CTRL + S        Start the screensaver now
    SUPER + CTRL + SPACE    Wallpaper picker (double-click the desktop: left for
                            wallpapers, right for colour themes)
    SUPER + CTRL + W        Wallpaper picker too
    SUPER + CTRL + SHIFT + SPACE   Colour theme (Gruvbox, Nord, Catppuccin... 23 of them)
    SUPER + CTRL + T        Colour theme too
    SUPER + CTRL + I        Stay awake: no screensaver or lock (a cup shows in the bar)
    SUPER + CTRL + M        Mute or unmute the microphone
    SUPER + CTRL + D        Screens: extend, mirror or one screen (projector)
    SUPER + CTRL + O        Toggles: do not disturb, stay awake, night light, gaps...
    SUPER + CTRL + H        Hardware: touchpad, touchscreen, keyboard light, graphics
    SUPER + SHIFT + T       Activity (btop)
    SUPER + grave           Quake console: a terminal that drops down over everything
                            (SUPER + SHIFT + grave sends a window there)

  WINDOWS
    SUPER + W  (or Q)       Close window
    SUPER + arrows          Move focus
    SUPER + SHIFT + arrows  Swap window in that direction
    SUPER + F               Fullscreen
    SUPER + ALT + F         Maximise (keeps the bar)
    SUPER + T               Float / tile the window
    SUPER + O               Pop window out (float and pin); again to put it back
    SUPER + M               Minimise to the dock (floating workspaces; click the
                            app in the dock to bring it back)
    SUPER + G               Group windows together (SUPER + ALT + G leaves the group,
                            SUPER + CTRL + arrows moves within it)
    SUPER + P               Pseudo-tile (keep a window's own size in its tile)
    SUPER + J               Flip the split (side-by-side <-> stacked)
    SUPER + - / =           Narrower / wider
    SUPER + SHIFT + - / =   Shorter / taller
    SUPER + left-drag       Move window with the mouse
    SUPER + right-drag      Resize window with the mouse
    ALT + Tab               Next window (SHIFT for previous)
    SUPER + ALT + arrows    Join the group in that direction
    SUPER + ALT + Tab       Next window in the group (SUPER + ALT + 1..5 jumps)
    SUPER + ALT + HOME      Remember this window's width (SUPER + HOME puts it back)
    SUPER + BACKSPACE       Window see-through / solid
    SUPER + SHIFT + BACKSPACE   Gaps between windows off / on
    SUPER + CTRL + BACKSPACE    Keep a lone window square on a wide screen
    CTRL + ALT + DELETE     Close every window
    SUPER + C / X / V / A   Copy / cut / paste / select all, in every app (terminals too)

  WORKSPACES
    SUPER + 1..0            Go to workspace 1-10
    SUPER + SHIFT + 1..0    Send window to workspace 1-10
    SUPER + SHIFT + ALT + 1..0  Send window there but stay here
    SUPER + SHIFT + CTRL + arrows   Send window to the screen in that direction
    SUPER + SHIFT + ALT + arrows    Send this workspace to that screen
    SUPER + Tab             Next workspace (SHIFT for previous, CTRL for the one before)
    SUPER + L               Cycle this workspace's layout: tiling, scrolling, floating.
                            Floating workspaces are where the dock lives.
    SUPER + ALT + L         Cycle the layout the other way
    3-finger swipe          Switch workspace
    SUPER + S               Show / hide the scratchpad
    SUPER + ALT + S         Send window to the scratchpad

  TOOLS
    SUPER + CTRL + V        Clipboard history (search, click to copy again)
    SUPER + CTRL + E        Emoji picker
    ALT + Print             Record a region of the screen (same keys again to stop)
    ALT + SHIFT + Print     Record the whole screen
    ALT + CTRL + Print      Record the whole screen with your microphone
                            Recordings go to ~/Videos/Screencasts
    SUPER + CTRL + C        Capture menu (screenshot, recording, colour, text)
    SUPER + Print           Pick a colour on screen (hex copied)
    SUPER + CTRL + Print    Copy the text in a part of the screen (OCR)
    SUPER + CTRL + .        Convert a video or picture (MP4, WebM, GIF, PNG, JPG, WebP)
    SUPER + CTRL + R        Set a reminder ("20m stretch", "15:30 call home")
    SUPER + CTRL + ALT + R  List reminders (SUPER + CTRL + SHIFT + R clears them)
    SUPER + CTRL + ALT + T / B / W   Time / battery / weather as a notification
    SUPER + CTRL + ALT + D  Calendar (ALT + E: with the world clock)
    SUPER + CTRL + Z        Zoom in around the pointer (SUPER + CTRL + ALT + Z: out)

  NOTIFICATIONS
    SUPER + comma           Open the latest (its link or app)
    SUPER + ALT + comma     Dismiss the latest
    SUPER + SHIFT + comma   Dismiss all
    SUPER + CTRL + comma    Pick one of the latest's actions from the keyboard
    SUPER + SHIFT + ALT + comma   Recent notifications (pick one to copy it)
    SUPER + CTRL + ALT + comma    Do not disturb on / off (bell in the bar while on)

  PANELS
    SUPER + CTRL + A        Sound and brightness
    SUPER + CTRL + B        Bluetooth
    SUPER + CTRL + N        Network (Wi-Fi)
    SUPER + CTRL + P        Battery and power mode
    SUPER + CTRL + D        Screens
    SUPER + CTRL + 1..9     The bar's panels, left to right
    SUPER + CTRL + DELETE   Laptop screen off / on (with another screen plugged in)
    SUPER + CTRL + ALT + DELETE   Mirror the laptop screen / stop mirroring
    SUPER + /               Next scale for this screen

  OTHER
    SUPER + SHIFT + S       Screenshot a region      (or Print)
    SUPER + SHIFT + P       Screenshot the whole screen  (or SHIFT + Print)
    SUPER + SHIFT + Space   Hide / show the top bar
    Volume / brightness keys: hold ALT for 1% steps; SHIFT + brightness for max / min;
    SHIFT + mute for the next sound output; ALT + play for the next track
  TOP BAR (click the icons)
    Date and time           Calendar, with the player underneath while music plays
    Music icon              Shown beside the time while something plays; same panel
    Wi-Fi                   Networks, Wi-Fi on/off (right-click: full network menu)
    Bluetooth               Devices, Bluetooth on/off
    Volume / brightness     Sliders for both, audio output (scroll: volume,
                            right-click: mute)
    Battery                 Charge, time left, power mode (saver / balanced / performance)
    Keyboard layout         Shown only with two or more layouts; click to cycle
    Click outside a panel, press Escape, or click the same icon again to close it.

  DOCK (floating workspaces, along the bottom)
    Click an app to open or focus it; drag icons to rearrange them.
    Right-click an app to pin it, open a new window, or quit it.
    Right-click the grid button to make the dock hide until the pointer
    touches the bottom edge.

  Stuck? SUPER + Escape -> Log out, then pick "Ubuntu" from the gear icon
  on the login screen to return to GNOME.

  Edit keys in ~/.config/hypr/hyprland.lua (reloads on save).
