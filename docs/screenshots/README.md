# Screenshots

The main README expects these files in this folder:

| File | Shows |
|---|---|
| `desktop.png` | Two or three tiled windows with the top bar (the hero image) |
| `screensaver.gif` | The name animating on the screensaver (a `.png` works too; update the README link) |
| `lock.png` | The lock screen: name and password box |
| `launcher.png` | The app launcher open over the desktop |
| `terminal.png` | Alacritty with the prompt inside a git repository |
| `bar.png` | A close crop of the top bar |

See "Taking the screenshots" in the main README for the commands.
